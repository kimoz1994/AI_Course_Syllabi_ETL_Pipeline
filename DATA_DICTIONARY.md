# Data Dictionary — AI Course Syllabi

Canonical raw file: **`data/raw/AI_course_syllabi_CSV.csv`**
(source: [Kaggle — AI Course Syllabi](https://www.kaggle.com/datasets/ahmedabdulhakim/ai-course-syllabi), v2, 2024-08-10, **CC BY 4.0**)

## Provenance

- **Row** = one university AI course syllabus (**113 rows**, no duplicates).
- **Collection:** public syllabi found via Google search
  (`Artificial + Intelligence + AI + Course + Syllabus filetype:pdf OR filetype:html`).
- **Extraction:** manual, one submission per syllabus through a Google Form —
  each form question became a column. The file is therefore a *human-transcribed
  view* of the PDF, not machine-extracted text.
- **Coverage:** 18 countries (US 66, India 19, …), years 2000–2024
  (84 rows carry a year; the form stored it as `YYYY-01-01` dates).

## Raw → clean column mapping

Clean names are produced by `ai_syllabi_etl.clean.standardize_columns`;
non-null counts below are **verified from the shipped files** (raw → after cleaning).

| Raw header (exact) | Clean name | Type (clean) | Non-null raw → clean | Interpretation | Cleaning rule |
|---|---|---|---|---|---|
| `Which country ? ` | `country` | text | 107 → 107 (94.7 %) | Country of the institution | trim whitespace |
| `Which education institution ? ` | `institution` | text | 113 → 111 (98.2 %) | University / college name | sentinel `not mentioned` → missing |
| `Year ? ` | `year` | integer (nullable) | 84 → 84 (74.3 %) | Course year, stored raw as `YYYY-01-01` | first 4-digit group parsed to int; outside 1900–2100 → missing; later range-checked 1990–2030 |
| `What is the course title ? ` | `course_title` | text | 113 → 113 (100 %) | Official course title | trim |
| `What are the course prerequisites ? ` | `prerequisites` | text | 49 → 45 (39.8 %) | Listed prerequisites | `none` / `not mentioned` → missing (absence of prerequisites is *not* distinguishable from "not transcribed") |
| `What is the course description ?` | `course_description` | text | 113 → 89 (78.8 %) | Catalog description / syllabus intro | sentinel `not mentioned` → missing |
| `What is the course  content/topics?` | `course_topics` | text (multi-line) | 113 → 103 (91.2 %) | Topics covered — comma/newline/bullet (`○`) lists, sometimes full sentences | sentinel → missing; whitespace normalized; **split into items on newlines/bullets only** (commas kept inside phrases) for classification |
| `What are the course outcomes/objectives?` | `course_outcomes` | text (multi-line) | 64 → 64 (56.6 %) | Numbered learning outcomes | numbering (`1.`, `2)`) stripped when split into items |
| `Hardware or Software tools used in the course ? ` | `tools` | text (multi-line) | 46 → 46 (40.7 %) | Languages, frameworks, platforms (python, prolog, weka…) | trim; newline-separated values preserved |
| `Textbook/references used in the course ? ` | `textbooks` | text | 79 → 79 (69.9 %) | Textbook / references | trim |
| `Teaching method ? ` | `teaching_methods` | text (multi-value) | 113 → 96 (85.0 %) | Teaching methods, `;`-separated | sentinel → missing; split on `;` / `|` / newline for counting |
| `What are assessment methods ? ` | `assessment_methods` | text (multi-value) | 113 → 94 (83.2 %) | Assessment methods, `;`-separated | sentinel → missing; split on `;` / `|` / newline for counting |

## Derived columns

| Column | Where | Rule |
|---|---|---|
| `syllabus_id` | every cleaned/processed table | Stable sequential id `S001…S113`, assigned in raw row order **before** cleaning so raw ↔ clean stay 1:1 traceable |

## Sentinel values (converted to missing)

`""`, `not mentioned`, `n/a`, `na`, `none`, `-`, `--`, `not specified`,
`not available`, `none mentioned`, `not applicable`, `no prerequisites`
(case-insensitive, trimmed).

> **Interpretation caveat:** because extraction was manual, a missing value
> means *"the transcriber did not record it"* — it does **not** prove the
> original PDF omitted it. Treat completeness figures as form-coverage, not
> as syllabus content.
